# ChatGPT-Prompts für die Collage-Ausschnitte

Ich ergänze später: Farbakzente (Orange/Petrol), Rasterpunkte, Schatten, Animation.
Dateien bitte so benennen wie in der Spalte „Datei" (PNG, transparenter Hintergrund).

## Typ 1 – mit hochgeladenem Originalfoto (echte Personen, Flugzeug, Schiffe)

Originalfoto in ChatGPT hochladen, dann:

```
Bearbeite das hochgeladene Foto zu einem Ausschnitt für eine Vintage-Papiercollage in einem Erklärvideo.
- Das Hauptmotiv exakt wie im Original lassen: Gesicht, Proportionen und Details nicht verändern, nichts dazuerfinden.
- Hintergrund vollständig entfernen, transparenter Hintergrund (PNG).
- Schwarzweiß, kräftiger Kontrast, leichte Fotokörnung, wie ein alter Archiv- oder Zeitungsdruck.
- Rundherum ein schmaler weißer Papierrand, leicht unregelmäßig, wie mit der Schere ausgeschnitten.
- Kein Schatten, keine Farbe, kein Text, keine zusätzlichen Elemente.
- Motiv vollständig im Bild, nicht angeschnitten, hohe Auflösung.
```
