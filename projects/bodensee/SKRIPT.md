# Skript „Der See, der niemandem gehört" (Bodensee) – Entwurf 1

Stil: Karten-Doku (map_doc, wie Referenz 3). Ziel ca. 65–70 s, ca. 190 Wörter (ruhiges Tempo ≈ 2,8 Wörter/s).
`/` = kurze Pause, `//` = längere Pause, *kursiv* = Figuren-Zitat (etwas andere Stimme / augenzwinkernd).

## Sprechtext

Mitten in Europa gibt es einen See, / bei dem bis heute niemand weiß, / wem er eigentlich gehört. //

Das ist der Bodensee. / Drei Länder liegen an seinem Ufer: / Deutschland, / Österreich / und die Schweiz. /
Aber eine Grenze im See? / Gibt es nicht. //

Wie kann das sein? //

Früher brauchte man keine. / Rund um den See herrschten Fürsten, / Klöster / und Reichsstädte – / alle unter dem Dach des Heiligen Römischen Reichs. / Der See war einfach … der See. //

Doch dann geht die Schweiz eigene Wege. / Das Reich zerfällt. / Und plötzlich teilen sich mehrere Staaten das Ufer. /
Für den kleinen Untersee zieht man 1854 eine Grenze. / Für den großen Obersee? / Nie. //

Und so hat heute jedes Land seine eigene Meinung. /
Die Schweiz sagt: *„Ganz klar: Die Grenze verläuft in der Mitte."* /
Österreich sagt: *„Ganz klar: Der See gehört uns allen zusammen."* /
Und Deutschland? / *„Äh … wir legen uns da lieber nicht fest."* //

Das Verrückte: / Es funktioniert trotzdem. / Fischerei, / Schifffahrt, / Wasserschutz – / alles regeln die drei Länder gemeinsam. /
Nur die eine Frage klären sie nie. //

Und so trinken heute Millionen Menschen Wasser aus einem See, / von dem keiner sagen kann, / wem er eigentlich gehört.

## Vor der Veröffentlichung prüfen
* Grenzvertrag Untersee: 1854 (Baden–Schweiz) – Jahreszahl gegenprüfen.
* Positionen: Schweiz = Realteilung (Mitte), Österreich = Kondominium (gemeinsam), Deutschland = offiziell
  nicht festgelegt – gegenprüfen.
* „Millionen Menschen Trinkwasser" (Bodensee-Wasserversorgung, ca. 4 Mio. in Baden-Württemberg) – gegenprüfen.
